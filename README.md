# EXHALE

## EXplainable Healthcare AI with Linguistic Evaluation

> **Project Status: CLOSED**
> **Research & Experimental Project**

EXHALE is a research-oriented explainable AI framework developed to investigate how machine learning predictions for asthma risk can be translated into human-readable clinical reasoning and evaluated for explanation fidelity.

The project combines **classical machine learning, SHAP-based explainability, Large Language Models (LLMs), and semantic evaluation** using the **NHANES 2011–2012** dataset.

The primary research focus was not only predicting asthma risk, but also investigating whether LLM-generated explanations faithfully reflected the important features identified by the underlying machine learning model.

> **Note:** This repository represents a completed experimental research project. The work was closed after the experimental phase because the available results were not sufficient to support a publication-ready research contribution. The implementation, experiments, findings, and limitations are retained here for reproducibility and reference.

# Overview

EXHALE (**EXplainable Healthcare AI with Linguistic Evaluation**) was developed as an experimental framework for studying explainability in healthcare machine learning.

The framework follows a multi-stage pipeline:

1. Process publicly available NHANES health data.
2. Train and compare multiple machine learning models.
3. Optimize selected models using hyperparameter tuning.
4. Generate feature-level explanations using SHAP.
5. Provide SHAP-derived information to Large Language Models.
6. Generate natural-language explanations of model predictions.
7. Evaluate the generated explanations using lexical and semantic fidelity metrics.

The project explores an important question in explainable AI:

> **Does a natural-language explanation generated by an LLM actually preserve the reasoning represented by the underlying machine learning model?**

---

# Research Objectives

The project was developed with the following objectives:

* Develop machine learning models for asthma-risk classification using NHANES 2011–2012 data.
* Compare multiple classical ML algorithms using standard classification metrics.
* Investigate SHAP as a mechanism for interpreting individual model predictions.
* Convert feature-level SHAP information into natural-language explanations using LLMs.
* Compare explanations generated by different LLM architectures.
* Evaluate explanation fidelity using lexical and semantic approaches.
* Explore the use of semantic similarity and entropy-based measures for explanation evaluation.
* Investigate whether semantic evaluation can capture relationships that simple keyword matching may miss.

# Explainable AI

The project uses **SHAP (SHapley Additive Explanations)** to investigate the contribution of individual features to model predictions.

The implemented explainability analyses include:

* SHAP Summary Plot
* SHAP Feature Importance Plot
* SHAP Dependence Plot
* SHAP Force Plot

SHAP values provide feature-level contribution scores, allowing the project to examine which input variables contributed most strongly toward individual predictions.

These feature contributions were subsequently used as inputs to the LLM explanation pipeline.

# FEEM

## Fidelity Entropy Evaluation Metric

FEEM was implemented as a lexical evaluation approach for analyzing the correspondence between SHAP-important features and LLM-generated explanations.

The framework evaluates whether important features identified by the model are explicitly represented in the generated explanation.

### Evaluation Components

* Exact feature fidelity
* Weighted fidelity
* Entropy-based consistency
* Exact-match accuracy
* Cross-LLM lexical comparison

FEEM served as the baseline evaluation approach for comparison with the proposed semantic evaluation method.

---

# S-FEEM

## Semantic Fidelity Entropy Evaluation Metric

S-FEEM was developed as an experimental extension of the lexical FEEM approach.

The objective was to investigate whether explanation quality could be evaluated beyond exact keyword overlap.

S-FEEM combines four conceptual dimensions:

* **S — Semantic Similarity**
* **F — Feature Fidelity**
* **C — Consistency**
* **H — Hallucination Robustness**

The overall score is represented as:

```text
S-FEEM = αS + βF + γC + δH
```

where:

```text
α + β + γ + δ = 1
```

### Components

**Semantic Similarity**

Measures how semantically similar the generated explanation is to a reference explanation.

**Feature Fidelity**

Measures whether the explanation reflects features identified as important by SHAP.

**Consistency**

Measures the stability of explanations across repeated generations.

**Hallucination Robustness**

Attempts to identify or penalize claims that are not supported by the provided model explanation or input information.

### Important Note

S-FEEM should be considered an **experimental research framework**, rather than a clinically validated or standardized evaluation metric.

Further validation, benchmarking, and external evaluation would be required before making stronger claims about its general applicability.

# Experimental Results

## Machine Learning Performance

| Model               | Accuracy |   ROC-AUC |
| ------------------- | -------: | --------: |
| Logistic Regression |    0.872 |     0.779 |
| SVM                 |    0.874 |     0.763 |
| Random Forest       |    0.871 |     0.779 |
| XGBoost             |    0.864 |     0.754 |
| Tuned SVM           |    0.849 |     0.772 |
| Tuned XGBoost       |    0.820 | **0.787** |

Among the evaluated models, **Tuned XGBoost achieved the highest ROC-AUC (0.787)** and was therefore selected as the primary model for subsequent explainability experiments.

It is worth noting that the tuned model did not achieve the highest accuracy. This illustrates the difference between optimizing classification accuracy and optimizing ranking/discrimination performance as measured by ROC-AUC.

---

# FEEM Results

### Lexical Fidelity

| Model         | Fidelity | Weighted Fidelity | Entropy |
| ------------- | -------: | ----------------: | ------: |
| Llama 3.3 70B |    0.790 |             0.803 |   0.517 |
| Mistral Large |    0.750 |             0.692 |   0.228 |

The lexical evaluation showed differences between the two LLMs in both feature matching and entropy-based consistency.

Llama demonstrated higher lexical feature fidelity in the evaluated experiments, while Mistral showed lower entropy under the reported FEEM configuration.

---

# S-FEEM Results

### Semantic Fidelity

| Model         | Semantic Fidelity | Mean BERTScore Similarity | Semantic Entropy |
| ------------- | ----------------: | ------------------------: | ---------------: |
| Llama 3.3 70B |             0.860 |                     0.613 |            0.506 |
| Mistral Large |         **0.990** |                 **0.661** |            0.632 |

The semantic evaluation produced a different comparison from the lexical FEEM results.

Mistral achieved higher reported semantic-fidelity and BERTScore values in the evaluated experiments, despite Llama achieving higher lexical feature fidelity.

This difference highlights the motivation for investigating semantic evaluation rather than relying exclusively on exact keyword matching.

# Key Findings

The experiments produced several observations:

### 1. Model performance and explanation quality are separate concerns

The model with the strongest predictive performance does not automatically produce the most interpretable or faithful natural-language explanations.

### 2. Lexical and semantic evaluation can produce different conclusions

The FEEM results favored Llama on some lexical measures, whereas S-FEEM produced higher semantic scores for Mistral.

This demonstrates that exact feature-word matching and semantic similarity capture different aspects of explanation quality.

### 3. LLM explanations can vary across architectures

The evaluated LLMs produced differences in feature representation, semantic similarity, and explanation consistency.

### 4. Semantic evaluation may capture information missed by keyword matching

Two explanations can communicate similar reasoning using different terminology. A semantic evaluation approach can potentially identify such relationships where exact keyword matching may fail.

### 5. Explanation evaluation requires further validation

The experiments provide preliminary evidence for investigating semantic explanation fidelity, but larger-scale experiments and independent validation would be necessary before drawing generalized conclusions.

# Limitations

The project was closed after the experimental phase, and several limitations were identified.

## Dataset Limitations

* The experiments were based on NHANES 2011–2012 data.
* The dataset represents a specific population and time period.
* External datasets were not used for independent validation.

## Model Limitations

* The observed ROC-AUC values were moderate.
* Hyperparameter tuning did not consistently improve all performance metrics.
* The experiments do not establish clinical utility or deployment readiness.

## LLM Limitations

* LLM-generated explanations may contain unsupported or generalized statements.
* Results may vary between model architectures and generations.
* Explanation quality depends on the quality and representation of the information supplied to the LLM.

## S-FEEM Limitations

* S-FEEM is an experimental framework rather than a standardized evaluation metric.
* Its weighting parameters require further justification and validation.
* The evaluation was conducted on a limited experimental setup.
* Additional human expert evaluation would be required to establish clinical relevance.
* Broader benchmarking against established explanation-evaluation methods would strengthen the approach.
